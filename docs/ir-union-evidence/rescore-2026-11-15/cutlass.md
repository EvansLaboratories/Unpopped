## Method note

Rows examined: 80 of the 84 non-Yes, non-n/a rows at a634b09 (the 37 changed plus 43 left as they were, of which about 25 were looked at hard and are listed above), and the four first-re-score Yes moves (74, 85, 86, 89) were re-confirmed. Rows verified against code by grep of the cited symbol plus the cited test file; I did not run any tests (no cargo allowed), so "a test runs it" means the test file exists at 78c7d38e and its assertions name the behaviour. One gap: I did not open `S/oracle/kernel_async.rs` or `S/oracle/kernel_mma.rs` line by line; the traps and gather/scatter behaviour are taken from the test files' assertions and the `kernel.rs` docs.
