## 5. Judgement calls and what I did not verify

- **Row 58 No -> Partial is the weakest move.** The brief's rule is a named symbol and a named test; both exist (`BarrierKind::Named`, `kernel_named_barrier.rs::a_producer_group_hands_a_tile_to_a_consumer_group_twice`). If the PM wants one rule, move 58 back to No (headline 11/40/14/1).
- **Row 21 No -> Partial** counts a hint on `CopyAsync` only; the oracle ignores it by design. If "cache hints on load/store" is read literally (plain `ld`/`st`), it is still No.
