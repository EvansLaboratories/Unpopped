# Idioms in eight kernel languages that the conformance kernels do not yet express (2026-11-27)

**Task:** pm-kernels [TASK] `more-rows` (survey row). **Standard:** CireSnave 2026-11-11, quoted by pm-kernels: *"if Unpopped's IR does not support something one of those kernel languages is capable of then that IR is not yet complete to my standards"*. Facts only. Each gap is a **candidate row for the primary (`unpopped`), not a build** by this lane.

**How it was made, and its limits.** Three read-only Sonnet agents each read public docs for their languages and grepped `crates/unpopped/src/{kernel.rs,ir.rs,mma.rs}` at `origin/main` `3088a0b6` (0.60.25); this lane did not re-read the pages. Status `READ` = the agent read the page, `UNVERIFIED` = memory, a search snippet or a page that did not load. A grep count of 0 is a null from a text search, not a proof of absence; each agent named a positive control (a name that exists). This lane re-ran the greps for `elect.sync|ElectOne`, `setmaxnreg|max_nreg`, `Pipelin`, `Philox`, `clmul`, `dp4a`, `Semaphore`, `autodiff`, `syncthreads_count`, `TensorDescriptor|TensorMap` and `ActiveMask` on the same files: all 0 (the case-insensitive `elect` hit in `kernel.rs:194` is the word "selects"; `Quad` hits are "quadrant"). Versions: no page showed a release tag unless stated. The older surveys in `docs/ir-union-surveys/` predate most of the kernel-layer `Stmt` set and were not re-read here.

**Holds.** Rows marked **HELD** touch a standing patent hold (`HANDOFF` rule 4 / `docs/PATENT-SWEEP.md`): they are listed as facts about the language and are NOT candidates while the hold stands. Texture-shaped rows are listed as facts only.
