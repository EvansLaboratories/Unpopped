# unpopped-slang (deprecated, no longer developed)

`unpopped-slang` was the Slang compute-shader emitter and frontend for [Unpopped](https://github.com/EvansLaboratories/Unpopped).
It has been superseded. Slang now lives in its own project, fishstringer:

- **`fishstringer-slang-parse`** 0.0.14: the Slang parser and frontend.
- **`fishstringer-slang-emit`** 0.0.14: the Slang emitter.

Use those crates instead. This 0.35.4 release contains no code and no dependencies; it exists only so that this page points
you there. Earlier versions (up to 0.35.3) are unchanged and remain on crates.io.
