kind: added: `unpopped-cpu-c` emits `AllocDecl::dyn_layout` as C
---
The serial C emitter spells a `dyn_layout` (the follow-up named in `docs/design-dynamic-layout.md` section 5): the physical offset of a logical index is C arithmetic over the scalar parameters (colexicographic coordinates over the flattened shape times the strides), and the oracle's launch-time proof (shape leaves at least 1, no negative stride, size equal to the extent, cosize inside it, within the 4 Mi enumeration cap, no two indices on one offset) is emitted at the top of the kernel function and returns **status 4** before any thread runs, exactly where the oracle traps with `KernelTrap::DynLayout`. Declined by name (so the layout is never bypassed) in a callee, a kernel with a Device barrier, a peer access or several devices, and one that moves fragments (`Mma`, `MatrixLoad`/`MatrixStore`) or calls a callee; a parameter that is a struct field is not spelled. Tests: the C against the oracle over two layouts (two-term row-major and a three-term nested) and a sweep of argument sets, both arms reached; mutants (each offset term of the access zeroed, the injectivity run skipped) change the status or the bytes. Additive; `unpopped-cpu-c` only.
