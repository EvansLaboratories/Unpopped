kind: Added: `unpopped::fixtures` (feature `fixtures`): one checker-valid kernel or module per `Stmt` variant, for emitter decline tests (U60)
---
Non-breaking, additive, behind the `fixtures` cargo feature (normal builds do not carry it). `unpopped::fixtures::fixtures()` returns one small kernel, or one module with its entry index, for each of the 42 `Stmt` variants, so an emitter's decline test can assert the emitter's own refusal text while the checker passes; `fixture(name)` looks one up and `needs(name)` says what it needs. `variant_name` is an exhaustive `match` with no wildcard arm and `ALL` is generated from the same list, so a new `Stmt` variant fails the build under the feature until it has a fixture. Unit tests assert that every variant has exactly one fixture, that every fixture passes `check_kernel` or `check_module`, and that each fixture really contains a statement of its own variant. `CollectiveTuple`, `Call`, `CallTuple` and `ExternCall` are modules; `MulticastLoadReduce` needs a two-device launch; `Tcgen05Mma` and `Tcgen05Ld` use tensor memory; `Wgmma` and `Tcgen05Mma` use the oracle-only row-major operand layouts.
