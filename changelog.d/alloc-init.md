kind: added: `AllocDecl::init`, an initial table on a `Constant` or `Private` allocation (U40/U66)
---
`AllocDecl::init: Option<Vec<i128>>` (`with_init`; one value per element by logical index, a float as its bit pattern; absent when none, so a kernel without one keeps its text and revision hash) and `KernelError::AllocInit`. `check_kernel`: only `Constant` or `Private`, a `Static` extent, one value per element each in the element's range, no layout beside it; a store into a `Constant` table stays refused. The oracle reads a `Constant` table (read-only, the same in every block) and gives every thread its own `Private` copy; a `Constant` allocation with no values stays unreadable. `unpopped-cpu-c` spells both and declines by name where a table would be dropped (a callee, a Device barrier, a peer access, several devices, a `Constant` with no values). The walker half (lifting `__constant__`/`static const` arrays) is not built; the other emitters keep declining until they opt in. Additive (`AllocDecl`, `KernelError` non_exhaustive). Patent: a table of integers and bit patterns copied into storage: no hardware, no statement; no patent read is claimed.
