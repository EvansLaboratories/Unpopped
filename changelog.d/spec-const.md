`KernelFn::spec_consts` (`SpecConst`, `SpecValue`, `KernelFn::with_spec_const`, `KernelError::BadSpecConst`): a scalar parameter fixed when the kernel is built. The oracle binds its default; cpu-c declines by name. Additive: an empty list is not serialized, so a kernel without one keeps its text and revision hash. Also documents `BarrierKind::Named`/`NamedArrive` `count` as a count of arriving threads that traps on disagreement (doc only). SpecConst: outside as read vs GB2516358A; no spec-constant patent found: not a clearance.
